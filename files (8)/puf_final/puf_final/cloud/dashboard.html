Device ID Key (64 hex = 256 bit) Key-check tag Info label
–
Copy the three values from the PUF dashboard's Fuzzy extractor tab: the final 256-bit key, the key-check tag and the construction label (use the label exactly as shown, e.g. SRAM-PUF-FE-v4|BCH(256,131,t=18)). The server accepts the key only if it is exactly 256 bits and the tag equals SHA-256("PUFFE-check" ‖ key). Registration is the one time the key crosses the network, so use it only on a network you trust (or HTTPS). Each ESP32 needs its own Device ID and its own key.
